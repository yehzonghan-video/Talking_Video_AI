# 自動粗剪與字幕整合修復（2026-10-28）

根因：上一版只移除 Python 時間軸的審核鎖定，JavaScript `buildMap` 仍要求刪除片段 `confirmed=true`。自動停頓／重講本來就沒有人工確認，因此前端推導時間軸直接失敗，連字幕推導及輸出請求都無法完成。分析流程另未呼叫字幕生成，只有介面上的手動生成按鈕；沒有字幕軌時前端 disabled、輸出亦為無字幕。字幕儲存端仍有殘留確認限制。

修復：前後端確認欄位皆作舊資料相容用途，不作保存／輸出條件。時間、空字、重疊及來源驗證照常執行。分析成功與 Gemini 失敗的本機降級路徑均執行 `prepare_delivery`，建立自動時間軸、沿用聲學辨識生成字幕與保守腳本校正。快取結果與舊專案開啟時也補齊，沒有缺項就不寫入、不呼叫 ASR 或 AI。已有人工時間軸／字幕與字幕關閉偏好保留。

單一有效資料：SQLite 專案 revision、來源座標字幕、目前時間軸與樣式為已保存版本。瀏覽器互動保留未保存快照；輸出按鈕將此快照傳給 `save_document`，通過版本檢查後一次保存，再將回傳專案交給 `export_mp4`。舊版本草稿遇到新版時顯示衝突，提供下載及重新載入，避免默默覆蓋。播放仍在瀏覽器執行，不為修字或樣式變更呼叫 FFmpeg。

實測：255 項 Python、11 項 JavaScript 回歸；新增整合測試實際生成 8 秒黑底音訊影片，完成自動重講刪除、繁體字幕生成、未確認旗標保存、修改字幕與黃色樣式後輸出；解碼成品檢查白字與黃字像素，關閉字幕成品黑底像素驗證。既有測試涵蓋直／橫式輸出、音畫同步、缺字型、缺 FFmpeg、剪輯映射與資料保留。

本機瀏覽器合成示範已看到字幕覆蓋影片；修改文字後即時更新，直接按輸出後出現 MP4 完成與下載，不按人工確認。瀏覽器使用保留片段跳轉做非破壞預覽，切點仍受播放器跳轉延遲限制，正式成品由 FFmpeg 裁切。
